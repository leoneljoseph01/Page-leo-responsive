# Leonel Advocacia - Site Profissional

Bem-vindo ao site profissional da **Leonel Advocacia**. Este é um site responsivo e moderno desenvolvido para apresentar os serviços jurídicos especializados em direito migratório, trabalhista, criminal e civil.

## Características

- **Design Responsivo**: Totalmente otimizado para dispositivos móveis, tablets e desktops
- **Interface Moderna**: Design elegante e profissional com paleta de cores sofisticada
- **Menu Mobile**: Navegação intuitiva com menu hamburger para dispositivos móveis
- **Formulário de Contato**: Formulário funcional com validação de dados
- **Smooth Scrolling**: Navegação suave entre seções
- **Animações Suaves**: Efeitos visuais que melhoram a experiência do usuário
- **Otimizado para SEO**: Estrutura semântica e meta tags apropriadas

## Estrutura de Arquivos

```
leonel-advocacia/
├── index.html          # Arquivo principal do site
├── styles.css          # Estilos CSS responsivos
├── script.js           # Funcionalidades JavaScript
├── logo.png            # Logo da Leonel Advocacia
└── README.md           # Este arquivo
```

## Como Usar

### Opção 1: Abrir Localmente
1. Baixe todos os arquivos para uma pasta no seu computador
2. Abra o arquivo `index.html` em seu navegador web
3. O site carregará com todas as funcionalidades ativas

### Opção 2: Hospedar em um Servidor Web
1. Faça upload de todos os arquivos para seu servidor de hospedagem
2. Certifique-se de que todos os arquivos estão no mesmo diretório
3. Acesse o site através do seu domínio

## Personalização

### Cores
As cores principais podem ser alteradas no arquivo `styles.css` nas variáveis CSS:
```css
:root {
    --primary-color: #1a2a40;      /* Azul escuro */
    --secondary-color: #d4af37;    /* Dourado */
    --text-color: #333;             /* Texto escuro */
    --light-bg: #f8f9fa;            /* Fundo claro */
}
```

### Conteúdo
Todos os textos podem ser facilmente editados no arquivo `index.html`. Procure pelas seções comentadas para encontrar facilmente o que deseja alterar.

### Logo
Para alterar a logo, substitua o arquivo `logo.png` por sua nova imagem e certifique-se de que o nome do arquivo permaneça o mesmo.
